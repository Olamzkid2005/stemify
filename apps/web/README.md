# Stemify web (`apps/web`)

Next.js (App Router) frontend for the Stemify stem separator. Deployed to Vercel.
The product plan lives in the repository root: `STEM_EXTRACTOR_PLAN.md`.

## Develop

```bash
npm install
npm run dev -w apps/web
```

Open http://localhost:3000.

## Scripts

- `npm run lint -w apps/web` — ESLint
- `npm run build -w apps/web` — production build (includes typecheck)
